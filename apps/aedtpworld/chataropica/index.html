Chataropica is an instant messaging app by AEDTP WORLD for Android and Windows, with web access at chat.aedtpworld.com. Android package is com.aedtpworld.chataropica. Both versions are 1.0.0.0 initial release and free. It offers direct messaging between registered users categorized as personal, business, or artist. Messaging starts via URLs like chat.aedtpworld.com/index.php?with=username, for example with caylaai. Chat is only for logged-in users. Interface shows logo and online user count in header. Chat list shows display name, username and verification. Examples include AEDTP WORLD and Cayla AI. Features include one-to-one messaging, bold, italics, strikethrough and lists, auto-linked https URLs, @username mentions, verification badges green for personal, black for business, blue for artist, day and night themes, avatar set via external URL, no file uploads.

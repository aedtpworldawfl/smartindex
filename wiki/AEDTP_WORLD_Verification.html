AEDTP WORLD VERIFICATION

AEDTP WORLD VERIFICATION is the Global Smartest WIKI METADATA Engine. It is a pro PHP version with server-side metadata handling built by AEDTP WORLD.

Purpose

AEDTP WORLD is a global technologies, business, developer, and content platform dedicated to providing quick, relevant metadata results across artists, music, biography, business, education, news, and more — all in a single platform. This verification system ensures the integrity and accuracy of all wiki metadata published under the AEDTP WORLD FREE LICENSE (AWFL).

Helpers

  • sanitize() — Prevents XSS using HTML escaping
  • loadMetadata() — Loads all stored metadata
  • saveMetadata() — Saves a single metadata entry
  • deleteMetadata() — Deletes a metadata entry by key
  • autoUrl() — Builds auto-generated URL for category + name

Request Handling

POST Save

Requires subject_name and primary_category. Builds category URLs — uses submitted value or falls back to auto-generated. AWFL is always auto-generated readonly. Entry contains subjectName, primaryCategory, categories, timestamp.

POST Delete

Requires key. Deletes entry if exists.

GET Export

If ?export=1 — exports all metadata as JSON file

GET Fetch All

If ?fetch_all=1 — returns metadata as JSON for live table refresh

Purpose

AEDTP WORLD FREE LICENSE (AWFL) WIKI META open encyclopedia built for discovery and connection.

Features

  • Search — Wiki search with live results dropdown, search results max 60vh
  • Pages Sidebar — Filter pages, page count, sort by updated desc, active left border accent
  • Editor — Contenteditable wiki-content with placeholder, toolbar always visible on edit
  • Toolbar — Format H1-H6, P, Pre, Blockquote, Bold, Italic, Underline, Strike, Mark, Code, Sup, Sub, Lists, Align, Indent, Font Size, Font Family, Text color, Highlight, Clear, Link, Image, Video, Audio, Table, HR, Note/Warning/Tip boxes, Undo/Redo, TOC
  • Tools Panel — Page Actions Edit, Save & Publish, Create New Wiki, Export HTML, Export All, Copy All, Heading Blocks, Inline Format, Blocks & Lists, Alignment, Insert Media, Infobox, Color, Clipboard & History, Page Settings Rename, Change Category, Word Count, Print
  • Status Bar — Words, Chars, Saved/Unsaved, Pages, Storage KB
  • Modals — Create New Wiki Page with slug preview /wiki/slug.html, Insert Link/Image/Video/Audio, Rename, Change Category pills, Infobox with fields, Wordcount
  • Categories — Uncategorized, AI, Apps, Artists, Bible, Developer, Education, Music, News, General
  • Infobox — Right floated 260px, title gold, field/value table, mobile full width
  • Mobile — All fit, no cut, toolbar scroll, infobox 100%, tables scroll, sidebar + tools full width order 3

Windows is an operating system developed by Microsoft.

Overview

Windows is a computer operating system built for PCs, laptops and tablets and available on desktops and devices worldwide.

Features

  • Runs apps, games and programs
  • Has Start Menu, Taskbar and File Explorer
  • Supports touch, keyboard and mouse
  • Has Microsoft Store and Copilot
  • Helps with work, school and gaming

History

Launched November 1985 as Windows 1.0, major updates with Windows 95, Windows XP, Windows 10 and Windows 11.

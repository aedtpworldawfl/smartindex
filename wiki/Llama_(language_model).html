Overview

Llama is an open source AI model built by Meta and used to power Meta AI on WhatsApp, Instagram, Facebook and Messenger.

Features

  • Answers questions and writes text
  • Helps with coding and ideas
  • Generates images with Meta AI
  • Can be used by developers
  • Runs in many languages

History

Launched February 2023 as Llama 1, major update with Llama 3 in April 2024, became the base for Meta AI.

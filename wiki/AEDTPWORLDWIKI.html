AEDTPWORLDWIKI

AEDTPWORLDWIKI is a free, open, community-editable encyclopedia by AEDTP WORLD. Anyone can create and edit a page.

Purpose

The purpose of AEDTPWORLDWIKI is to provide a free encyclopedia platform where users can browse articles on people, places, technology, and more. It is the homepage that includes search, category browser, recently updated pages, and create button.

How It Works

AEDTPWORLDWIKI loads wiki configuration and data, then renders pages with safe HTML escaping.

  • Loads configuration (credentials excluded)
  • Loads wiki data
  • Loads category list
  • Generates page links
  • Uses HTML escaping for XSS protection

Search

  • Gets search query from request
  • Converts to lowercase for matching
  • Searches in title and tags
  • Shows results count and list
  • If no results, shows "No pages found" with Create Page

Recent Pages

  • Sorts by last modified descending
  • Takes first 8 pages
  • Displays as recent cards

Category Counts

  • Counts entries per category
  • Shows count per category card

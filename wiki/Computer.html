Computer

A computer is an electronic device that takes information, processes it, and gives back a result.

Computers are used for work, school, games, music, videos, and talking to people around the world.

Every computer follows the same basic idea: input, process, output.

What Is a Computer

A computer is not just a laptop or a desktop. A phone is also a computer. A tablet is a computer. Even a smart TV has a computer inside.

A computer can:

  • Store information
  • Follow instructions
  • Do maths very fast
  • Show pictures and videos
  • Connect to the Internet

Parts of a Computer

Hardware

Hardware is the parts you can touch.

  • Monitor - Shows pictures and text
  • Keyboard - Used to type
  • Mouse - Used to point and click
  • CPU - The brain of the computer, it does the thinking
  • RAM - Short-term memory, helps programs run fast
  • Hard Drive / SSD - Long-term storage, where files are saved
  • Motherboard - Connects all parts together
  • Speaker - Makes sound

Software

Software is the programs you cannot touch.

  • Operating System
  • Browser
  • Games
  • Word processor
  • Antivirus

Without software, hardware cannot do anything.

Types of Computers

Desktop Computer

A desktop computer stays on a desk. It is strong and easy to upgrade.

Laptop Computer

A laptop is small and portable. You can carry it anywhere. It has a battery.

Tablet

A tablet is a flat touch-screen computer. It has no keyboard, you touch the screen.

Smartphone

A smartphone is a small computer in your pocket. It can call, text, take photos, and run apps.

Supercomputer

A supercomputer is a very powerful computer used by scientists for weather, space, and research.

How a Computer Works

A computer works in 4 steps:

  1. Input - You type, click, or speak
  2. Process - The CPU thinks and follows instructions
  3. Storage - It saves the work in memory
  4. Output - It shows the result on screen or speaker

Example:

  • Input: You type Hello
  • Process: Computer understands the letters
  • Output: Hello appears on the screen

Operating Systems

An operating system is the main software that controls the computer.

  • Windows
  • macOS
  • Linux
  • Android
  • iOS

Without an operating system, you cannot open apps or files.

What Computers Are Used For

  • Learning and school
  • Work and business
  • Talking to friends and family
  • Watching videos and listening to music
  • Playing games
  • Making Artificial Intelligence
  • Building websites like AWFLWIKIWORLD
  • Banking and shopping online
A computer is only as smart as the person using it.

History of Computers

  • 1800s - Charles Babbage designs the first computer idea, the Analytical Engine
  • 1936 - Alan Turing describes the modern computer idea
  • 1940s - First large electronic computers are built
  • 1970s - Personal computers start to appear
  • 1980s - Computers enter homes and offices
  • 2000s - Laptops and internet become common
  • 2010s - Smartphones become computers for everyone

Computer and the Internet

Computers connect to each other through the Internet.

The Internet lets computers:

  • Share files
  • Send messages
  • Show websites
  • Play games together

Good and Bad of Computers

Good:

  • Very fast
  • Can store a lot of information
  • Helps people learn and work
  • Connects the world

Bad:

  • Can break or get viruses
  • Can be addictive
  • Needs electricity
  • Can be used for hacking and scams

A computer is a tool. What matters is how you use it.

Computer Words to Know

  • CPU - Central Processing Unit, the brain
  • RAM - Random Access Memory, short-term memory
  • ROM - Read Only Memory, permanent memory
  • USB - A port to connect devices
  • Wi-Fi - Wireless internet
  • File - A piece of saved data like a photo or document

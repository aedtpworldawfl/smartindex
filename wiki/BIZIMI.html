Data Flow

  • API /social/api.php?action=get_feed&type=all|video|image
  • Feed item: contentType video/image, username slug title likes rank videoUrl imageUrl
  • href /social/{username}/{videos|images}/{slug}.html
  • ytEmbed regex youtube.com/watch?v= or youtu.be/ -> else video tag muted preload metadata
  • Like: POST action like_video/like_image {username slug}, returns likes liked, requires login else openLogin
  • Session: GET action=session -> data.username, nav rewrites to Help Upload @session Profile

AEDTP WORLD

Written by aedtpworld ✔ Verified 

AEDTP WORLD is a free, open digital ecosystem with the tagline "Discover And Connect." Built and maintained entirely under the AEDTP WORLD FREE LICENSE (AWFL), a license model the project describes as "forever contribution" — knowledge and tools on the platform are offered without paywalls, built to stay free and open over time.

The platform is a single-developer project: one founder builds and maintains every product in the ecosystem personally, using a lightweight, dependency-light technology stack — PHP, vanilla JavaScript, HTML/CSS, and JSON flat-file storage instead of a traditional database — running on shared Apache hosting.

Technical Foundation

Across its products, AEDTP WORLD follows a consistent set of house conventions:

  • JSON flat-file storage (no database) for most sub-projects
  • SHA-256 hashing for passwords and security answers
  • .htaccess rules blocking direct access to raw JSON data files
  • Session-based PHP authentication
  • Auto-generated static HTML pages on write operations
  • A shared visual identity: primary color #D10303, panel color #FFDE2C, and the Inter typeface
  • A canonical link tag and shared SEO meta head block on every page
  • Clean URLs (extension-hiding via .htaccess rewrite rules), forced HTTPS, and www-to-non-www redirection
  • A custom 404 "not found" page shared across the ecosystem

The site also runs its own lightweight PHP-based tooling rather than third-party services: a sitemap generator (the AWFL Sitemap Builder) that scans the site's HTML files and produces an XML sitemap, and a simple crawler that indexes page titles, snippets, images, and keywords into a search index powering the platform's built-in search engine.

AWFLWIKI

AWFLWIKI (AEDTP WORLD FREE LICENSE WIKI) is the platform's own encyclopedia-style wiki, located at /awflwiki/. It organizes user-submitted articles into fixed categories — Animals, Artists, Books, Business, Country, Creative, Dictionary, Education, Nature, People, Schools, Software, and Technology — plus a Help page. Users can sign up and publish articles per category (the category is locked after publishing, though title and content remain editable).

AWFLWIKI includes a rank and verification system: a user's rank is calculated from their published article count, and reaching rank 1 or higher grants a verified badge shown on their profile and articles. Admin accounts are created only through a manual claim-code process and have full moderation rights across the wiki, including editing or deleting any article.

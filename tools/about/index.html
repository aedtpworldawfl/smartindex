About

Simple by design

TOOLS is a flat-file directory of small, self-contained web tools. No database, no accounts required to use it — just folders of files served straight to the browser.

Every tool published here lives in its own folder under /tools/. An admin uploads a folder, it's listed instantly, and anyone can open it — no install, no sign-up.

How TOOLS works

Everything here is a plain folder of files. No database, no build step — pick a tool and go.

Opening a tool

Every tile on the directory opens /tools/{folder-name}/ directly. Nothing to install or sign in for — just tap and it loads.

For admins

/tools/login.php

Log in with the admin username and password. There's no self-registration.

/tools/upload.php

Publish a new tool, or update an existing one, by uploading a folder (or a single file) of files. The tool name becomes the folder name — spaces turn into underscores.

/tools/allfiles.php

Rename, delete a single tool, or clear every tool at once.

/tools/toolsfix.php

Re-syncs the tools index with what's actually on disk — fixes missing entries and removes broken/empty ones.

/tools/claim/

Lost access to the admin account? Search the username, verify your 12-character claim code, then set a new username and password.

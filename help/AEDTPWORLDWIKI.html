AEDTPWORLDWIKI
AEDTPWORLDWIKI is also an advanced wiki system which allows plain text, and allows users to use formatting tools to make it pro.
Accessible at: /aedtpworldwiki/
https://aedtpworld.com/aedtpworldwiki/

Who Is It For
This one is also simple but can confuse. It’s for someone who knows MD texts or a little bit of code.
But to make it easy to solve, we added:
- Preview Section: See how the wiki would look before publishing
- Media Resizer: Resize media before publishing

Permissions
- No Account Needed: You can create
- Anyone Can Edit: You can copy any code inside and edit
- Category: Users can create and choose the category of that wiki page

Code Rules - READ THIS
HTML Only: Use data inside body tags, or use buttons for easy text formatting.
Don’t include PHP thinking AEDTP WORLD can be corrupted. AEDTP WORLD is for good intentions.
If you think adding PHP or Python or wrong code in it can cause harm to AEDTP WORLD, then you might be joking. It won’t work.
So better go with: <b>, <i>, <p> etc... not <body> or <script> whatever.

Before Publishing
Make sure your wiki preview looks great or okay to be on AEDTP WORLD before publishing.

Admin Powers
Admin or AEDTP WORLD Teams can:
- Edit, delete, create, merge, whatever
- Merge Duplicates: Different pages talking about one subject will be merged as one

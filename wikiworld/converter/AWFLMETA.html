AWFLMETA Viewer

AWFLMETA · AEDTP WORLD Wiki Viewer Is a WIKI system of AEDTP WORLD FREE LICENSE WIKI, a Free Open Encyclopedia, Built And Powered by Forever Contribution, To Discover And Connect, Knowledge Is Unlimited.

Purpose

Viewer that fetches https://aedtpworld.com/wiki/awflmeta.json index, then loads each https://aedtpworld.com/wiki/{file} HTML, parses body and injects as cards min-height 100vh per fetch, with divider between.

  • Nav — Home Update News Create Upload Refresh, active bg rgba(240,180,90,0.18)

  • Status — loader-dots 8px #f0b45a pulse-dot 1.2s
  • Card — awflmeta-card bg rgba(22,26,34,0.75) radius 20px border rgba(255,255,255,0.04) shadow 0 12px 40px, padding 2rem 2.2rem margin-bottom 3rem, hover border rgba(240,180,90,0.12)

  • Divider — hr gradient transparent to rgba(240,180,90,0.2), icon 🌐
  • Scrollbar — 6px thumb rgba(240,180,90,0.3)
  • Responsive — 820px header 62px, 520px header 56px card 14px

Data Flow

  • Fetch awflmeta.json -> array of {name, file}
  • For each: fetch /wiki/{file}, DOMParser parse, doc.body.innerHTML inject
  • Error card with ERROR tag if fetch fails
  • EscapeHtml to prevent XSS

Common issues and how to fix them.

Upload failed / "Low Internet Connection"

This usually means the request to the server didn't complete. Check your connection, then try again. If it keeps happening, confirm the Music File URL is a direct, publicly accessible link (not a page requiring login) and try again.

Is It Free To Upload/Promote Music On Blue Melody, Or Does it Cost Much?

To Use Blue Melody And Its Features, It's Free, No Cost. You Don't Need To Pay.

All You Need To Do Is To Create Your Account And Carefully Read Through To Be Able To Succeed.

Edit Profile.

My artist name on a release doesn't match what I typed

By design, the Artist field always mirrors your profile's Artist Name — it can't be changed per‑release. To change it everywhere, update your Artist Name from Edit Profile.

I forgot my password

Use Recover Account and answer the security question you set when you signed up.

Can I edit a release after uploading?

No — releases can only be deleted by their uploader, not edited, once published. Delete it from your Music Library and re-upload with corrected details.

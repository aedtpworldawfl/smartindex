Chataropica

From AEDTP WORLD FREE LICENSE (AWFL), the free encyclopedia

Last Updated: 2026-09-08 18:23:22 308 words · 2 min read

Chataropica is an instant messaging application developed by AEDTP WORLD. It was initially released in 2026 and the current stable version is 1.0.0.0. The application is distributed for Android under the package name com.aedtpworld.chataropica and for Windows, with additional access available through a web interface at https://chat.aedtpworld.com.

The purpose of Chataropica is to provide simple direct messaging between registered users. Each user has a unique username and a profile. Accounts are divided into three categories which are personal, business, and artist. Personal accounts use a green verification badge, business accounts use a black badge, and artist accounts use a blue badge.

The main interface is called Chats. The Chats page is only visible to users who are logged in. At the top of the interface there is a header that displays the Chataropica logo on one side and the number of users currently online on the other side.

Messaging is started by using a direct link in the format https://chat.aedtpworld.com/index.php?with=username where username is the target user's username. When a user opens this link, a private conversation with that user is opened.

Messages support inline text formatting. Users can use bold, italics, strikethrough, and lists. Any URL starting with https is automatically converted into a clickable link. Users can mention other users by typing at symbol followed by username, and the mention becomes a link to that user's profile.

For profile pictures, Chataropica does not allow direct file uploads. Users set their avatar by providing an external image URL. The system also supports two visual themes which are day theme and night theme.

The application is freeware. It is owned and maintained by AEDTP WORLD. The official website is https://chat.aedtpworld.com and the official icon is hosted at https://aedtpworld.neocities.org/icons/chataropica.png. The application is designed to be lightweight and works similarly to other messaging platforms but with a focus on username based direct access and simple web integration.
